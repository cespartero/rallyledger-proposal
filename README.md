# RallyLedger: Club Championship proposal

A one-page, scrolling version of the Club Championship Series proposal, published with GitHub Pages.

- Scroll, or use the arrow keys / Space to move between slides; the dots on the right jump to any slide.
- Press **N** to show the speaker notes.

Everything is in `index.html`. To update the site, change that file and merge the change into `main`; GitHub Pages republishes it within a minute or two.
